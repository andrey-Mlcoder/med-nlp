# AI мониторинг диабетической стопы

Сервис для автоматического расчёта площади раны по фото и отслеживания динамики заживления диабетических язв стопы. Предоставляет REST API для загрузки изображений, получения результатов анализа, а также веб-интерфейс на Gradio для врачей и пациентов.

## Быстрый старт

### Предварительные требования
- Docker и Docker Compose
- Git
- Python 3.12+ (для локальной разработки)
- NVIDIA GPU (опционально, для ускорения инференса)

### Установка и запуск

1. **Клонировать репозиторий**

git clone https://github.com/andrey-Mlcoder/med-nlp.git
cd med-nlp

2. **Настроить переменные окружения**

Создайте файл .env в корне проекта.
Примеры заполнения есть в проекте.

3. **Запустите проект**

docker-compose up -d

4. **Проверить работу сервиса**

curl http://localhost:8080/health/
Должен вернуть: {"status": "healthy", "database": "ok"}

5. **После запуска сервиса документация доступна по адресу**

Swagger UI: http://localhost:8080/api/docs

6. **Веб-интерфейс**

Gradio UI: http://localhost:7860

#### Требования к системе

- Docker 20.10+

- Docker Compose 2.0+

- 4+ GB RAM (рекомендуется 8 GB для GPU)

- 10+ GB свободного места на диске

- NVIDIA GPU + nvidia-container-toolkit (опционально)

##### Примечания

ML модель: Unet + MIT-b1 (Segmentation Models PyTorch)

База данных: Данные сохраняются в Docker volumes

Асинхронная обработка: ML-инференс выполняется воркером через RabbitMQ, не блокируя API.

Аудит всех действий: каждое действие логируется в таблицу AuditLog.

Тесты: Все тесты используют изолированную тестовую БД
